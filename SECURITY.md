# Security and privacy

Reference photographs may contain biometric and personal data. Process only images for which the operator has an appropriate legal basis and explicit permission.

This portfolio repository intentionally excludes:

- API keys and production environment files;
- real people, customer records and generated customer images;
- private network paths, database addresses and internal prompts;
- model weights and copied third-party repositories.

For production use, add authentication, authorization, encryption, audit logs, malware scanning, rate limiting, retention controls and permanent deletion. Do not expose uploaded files through guessable public URLs. Rotate any credential that has ever been committed.
